Everything You Need

Every feature is production-grade, not a demo stub. Each decision has a reason behind it.

JWT Authentication

Dual-token architecture — short-lived access tokens with long-lived refresh tokens. Automatic rotation with server-side replay attack detection: if a used token is resubmitted, all sessions are immediately wiped.

Access TokenRefresh TokenRotationReplay Detection

Role-Based Access Control

Three-tier RBAC — user, moderator, admin. Enforced via composable middleware. Ownership checks for resource-level permissions.

Rate Limiting

Per-route limiters tuned to attack surface. Auth: 10 req/15min. Public reads: 60 req/min. Global: 100 req/15min. Rate limit headers included.

Input Validation

Comprehensive express-validator chains for every endpoint. Structured error responses with field-level details. Client never sees raw DB errors.

Security Hardening

7 security layers — Helmet, CORS, NoSQL injection prevention, XSS sanitization, bcrypt cost factor 12, body size limits, and account lockout.

Swagger Documentation

Full OpenAPI 3.0 spec at /api-docs. Interactive UI with persistent authorization and schema definitions for every model and endpoint.

Structured Logging

Winston with daily rotating files — separate error, combined, exception logs. Colorized console in development. Configurable log level via env vars.

Aggregation Pipeline

MongoDB $group pipeline for product stats by category — count, avg/min/max price, total stock. Real aggregation beyond basic CRUD.

Security Layers

Defense-in-depth — multiple independent layers so no single failure compromises the system.

01

HTTP Security Headers

Helmet sets HSTS, CSP, X-Frame-Options, and more on every response.

helmet
02

CORS Policy

Configurable origin whitelist via ALLOWED_ORIGINS env var. Exposes rate limit headers. Credentials-aware.

cors
03

NoSQL Injection Prevention

Strips $ and . operators from all user-supplied input before it reaches the database.

mongo-sanitize
04

Password Hashing

bcrypt with cost factor 12. Passwords never stored or returned in plain text. Schema uses select: false.

bcryptjs
05

JWT with Separate Secrets

Access and refresh tokens use different secrets, different expiries, and unique jwtid per token.

jsonwebtoken
06

Rate Limiting

Three separate limiters tuned per route type. Auth: 10 req/15min. Public reads: 60 req/min. Global: 100 req/15min.

express-rate-limit
07

Account Lockout

After 5 consecutive failed login attempts, the account locks for 2 hours. Resets on next successful login.

custom
